# Historical documentation archive

Indexed: 2026-10-03. All 119 archived files in this subtree are historical.
Current product requirements, open decisions, order, and status live in the
[canonical roadmap](../roadmap.md); start with the [documentation index](../README.md).

Titles containing “canonical,” “final,” “current,” or “approved” describe their
original work period. Closed decision queues do not close today’s D1–D8. Passing
release reports do not validate the current six-phase roadmap. Historical plans
and UI specifications must not be executed without reconciliation with it.

Historical result bodies are preserved beneath a status notice. Retired planning
documents have status and cross-reference corrections; their old instructions
are not active. HTML and
JSON artifacts are preserved unchanged, including their embedded labels and
original references. Old source paths, commands, temporary evidence paths, and
external links are historical references and may no longer resolve.

Use this archive when investigating a specific behavior, migration, or prior
validation result. It is not required reading for every task.

The retired `docs/target-architecture.md` is now [target-architecture.md](./target-architecture.md).
The former `docs/superpowers/` tree is retained under `superpowers/` below.
The topic brief is an archived discussion; current intent is in
[product.md](../product.md) and [roadmap.md](../roadmap.md).
